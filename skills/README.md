# Skills System

This directory contains quick-reference skill files for common development tasks. Each skill file is a short guide (1-2 pages) that links to deeper documentation.

## Available Skills

1. **getting-started.md** - Set up the project for the first time
2. **add-api-route.md** - Add a new REST API endpoint
3. **add-react-page.md** - Create a new React page with routing
4. **database-migration.md** - Modify the database schema
5. **rbac-setup.md** - Implement role-based access control
6. **add-translation.md** - Add i18n translations
7. **testing.md** - Write unit and E2E tests
8. **deployment.md** - Deploy to production

## How to Use

1. Find the skill that matches your task
2. Follow the step-by-step instructions
3. Check the "See Also" section for related documentation
4. If stuck, refer to `/docs/` for detailed guides
